## 🌙 修复黑暗模式下液态玻璃高光、手机端体验与白板/创作页布局优化

针对用户反馈的暗色模式视觉刺眼、亮斑不协调、移动端遮挡以及白板/创作页空间比例问题进行了全面深度重构：

### 1. 彻底根除暗色模式下的不协调亮斑与过曝
- **消灭常驻亮斑**：暗色模式下将 `--lg-sheen-rest` 彻底归零（原本留存的 0.2/0.55 在黑底上会在卡片与控件顶部形成突兀的白色发霉状圆弧光晕，现彻底清除）。
- **小控件（`.lg-ctl`）净化**：小按钮（画笔、吸管、撤销、色号等）在深色模式下禁用大面积 `radial-gradient` 镜面层，避免数十个按钮顶部顶着死白光斑；触控设备全面禁用假光斑。
- **悬停高光柔和度收敛**：深色模式下 hover 不再混入生硬高反光（0.85 纯白），换为细腻微光边缘（rgba 0.20），保持深邃通透的玻璃质感。
- **系统深色自适应**：在 `@media (prefers-color-scheme: dark)` 媒体查询中同步对齐深色令牌，保证无需手动切换也能正确适配系统暗色。

### 2. 手机端与小屏体验大幅重构
- **侧边栏首屏让位**：创作工坊与白板画板的辅助教程侧栏（`.sb-root`）在手机端（≤900px）默认收起为单行轻量横条（“🎨 教程与说明  › 展开”，仅占 42px），再也不会霸占整屏挡住画布与核心工具；点击即可随时展开查阅。
- **移动端边距收紧**：将外壳 padding 收窄，释放被空边距吃掉的 70px 屏幕横向宽度，画布利用率达到最大。
- **工具条横滑支持**：白板页顶部命令条与创作页展示台工具栏支持平滑横向滑动（不折行、不重叠、触控热区 ≥42px）。
- **缩放控件避让**：手机端将画布上方的绝对定位缩放条移入正常排版流，不再遮挡右上角绘制区域。

### 3. 白板页与创作工坊布局合理化重排
- **白板画布释放空间**：右侧对照图与清单栏宽度收缩至 `240px~340px`，消除过度占宽造成的画布压扁；中窄屏下合理堆叠。
- **创作页空状态舒展**：修复了 `create.html` 内标签嵌套闭合顺序；在未上传图片时自动收起右侧空图例与无效导出按钮，主展示台居中舒展；生成图纸后右侧材料栏自适应展开。

## 🧊 全站换上了「液态玻璃」材质（Liquid Glass）

页面上的卡片、面板、工具条、按钮，全部换成了 Apple 最新的液态玻璃质感。

**它不是毛玻璃。** 毛玻璃只有模糊一层；液态玻璃是五层叠出来的，少一层就不像：

| 层 | 做了什么 |
|---|---|
| L1 基底 | 模糊 2px + **饱和度提到 175%**（玻璃会把背景颜色「提纯」，这一步最容易被漏掉） |
| L2 折射 | 四条边附近把背景**真的掰弯** —— 用一张倒角位移贴图 + SVG 滤镜，中心严格零位移 |
| L3 高光 | 四道方向不同的内阴影（顶最亮 1.5px → 底最弱）+ 一圈 0.5px 亮环，这是「厚度」的来源 |
| L4 镜面 | 鼠标划过时，玻璃上有一块高光**跟着指针走** |
| L5 分层 | 只用在功能层（导航 / 工具条 / 卡片 / 弹层）；画布、图纸预览这些内容层保持清晰，不做玻璃 |

### 实测数据

折射不是「看起来像」，是逐像素量出来的。在玻璃下面铺一张噪声网格，开关折射各截一张图做互相关：

| 位置 | 背景被挪动的距离 |
|---|---|
| 左边缘 | 5 px |
| 右边缘 | −6 px |
| 上边缘 | 3 px |
| 下边缘 | −6 px |
| **正中间** | **0 px** |

中心严格零位移 —— 也就是说卡片中间的文字和图案完全不会糊，只有四条边在「折光」。
另外还验证了：滚动背景时玻璃里的折射内容跟着变（不是贴了一张固定纹理）；指针移动时高光位置与玻璃表面像素同步变化。

### 两条兜底

- **只有 Chromium 认这种折射。** Safari / Firefox 会直接把整条声明丢掉（连模糊一起没），所以折射规则整条包在 `@supports` 里，外面永远保留一条纯模糊 + 饱和度的兜底规则 —— 这两个浏览器上你看到的是干净的磨砂玻璃，不会变成透明。
- **滤镜只挂在 `backdrop-filter` 上，绝不挂 `filter`。** 挂错的话元素自己的文字会被一起扭曲。

### 性能与无障碍

- 长列表页（图库一屏几十张卡片）里，**离屏的玻璃会先摘掉模糊**，滚动到附近 240px 再挂回来 —— 滚动时不会每帧合成上百层。
- 同一时刻最多挂 18 个折射滤镜，按卡片面积优先，离开视口立刻卸载。
- 设备核心数 / 内存偏低时自动降级为「只保留材质外观、不做实时模糊」。
- 开了系统「**减弱透明度**」→ 玻璃变成不透明底色，不做模糊与折射（这才是正确的替代方案，而不是把透明度调高）。
- 开了「**减少动态效果**」→ 高光不再有缓动过渡。
- 开了「**提高对比度**」→ 玻璃转为不透明并加深边界。

## 🖼 图纸缩略图现在真的「填满」了

之前图库里有些图纸看着明显偏小、留白很多，而且每张小得还不一样，摆在一起大小参差。

**原因不在卡片样式，而在图纸本身**：这些图纸都画在 32×32 的方格上，但四周普遍留了空白 —— 实测 62 个图纸里 **61 个有空白边距**，平均只占满 83%（横）× 77%（纵）。最夸张的一张内容只有 18×22，占了不到一半。缩略图照着整幅 32×32 渲染，图案自然就缩在中间。

**修法**：缩略图改为**按内容边界裁剪**（去掉四周空白），外框仍保持统一的正方形，所以网格依旧整齐、图案却真正撑满了。

效果（实测面积占比）：

| 图纸 | 修复前 | 修复后 |
|---|---|---|
| 原神派蒙应急食品 | 0.32 | **0.67** |
| 皮卡丘经典大头 | 0.57 | **0.75** |
| 柴犬治愈头像 | 0.54 | **0.66** |
| 新春红灯笼 | 0.52 | **0.63** |
| 平均 | 0.59 | **0.69** |

首页精选、图库索引、图库子页面三处都已生效。编辑器与导出仍使用完整画幅，不受影响。

## 🎨 色号终于和颜色对得上了（换用官方 Artkal 真实色卡）

之前有个不容易发现、但影响很大的问题：**同一个色号，在不同页面显示成完全不同的颜色**。

比如 `A10` 这个色号，在创作工坊里是「活力橙」，到了白板画板却变成了「酒红」。这不是显示 bug，而是站点里一直并存着**两套互相打架的色板**：一套照着 Tailwind 调色板的色值填，另一套照着 CSS 命名色填 —— 两套都不是真正的拼豆颜色。

### 现在改成了什么

全站统一改用 **Artkal Mini（2.6mm）官方色卡**，也就是拼豆圈通用的 **MA–MM 九大系列、共 221 色**：

| 系列 | 色系 | 色数 |
|---|---|---|
| MA | 黄、橙、杏、柠檬 | 26 |
| MB | 草绿、薄荷、橄榄、墨绿 | 32 |
| MC | 天青、湖蓝、藏蓝、灰蓝 | 29 |
| MD | 紫罗兰、葡萄紫、品红 | 26 |
| ME | 粉红、兰粉、浅肤色 | 24 |
| MF | 正红、砖红、玫瑰红、珊瑚红 | 25 |
| MG | 肤色、棕、棕金 | 21 |
| MH | 白、灰阶、黑 | 23 |
| MM | 灰绿、卡其、灰棕 | 15 |

### 对你有什么用

- **导出的色号可以直接拿去配珠**了。以前导出的 `A10`、`C18` 这类编号在市面上并不存在，照着买不到；现在导出的是 `MA14`、`MC11`，直接对着 Artkal 色卡买就行。
- **创作工坊和白板画板颜色一致**了，同一张图纸在两处看到的是同一个颜色。
- 左侧色板从 55 色扩到 **221 色**，配色自由度大了很多；色板档位保留了 72 / 88 / 144 / 221 四档。
- 62 个精选图纸全部按「最接近的真实色」重新映射过，**观感基本不变**，只是颜色换成了真能买到的。

### 一点说明

拼豆是实体塑料珠，**官方从来没有发布过十六进制色值**，网上各站的色值都是扫描近似，彼此会差几个色阶。我们采用的是两家数值完全一致的来源（beadchart.com 与 bitbead.app）交叉印证。如果想要更贴近实物，只能拿实体色卡人工校色。

另外顺手修好了图库子页面每次访问都报 404 的小毛病（缺网站图标）。

## 🔧 参数面板折叠后点不动、两种状态看起来一样，已修好

之前点「收起参数面板」之后，会出现两个很别扭的现象：**展开和折叠看起来一模一样**，而且**面板里的东西点不动**。这次把根因挖出来修掉了。

### 为什么会这样

不是按钮坏了，也不是浏览器抽风，是四个布局问题叠在一起：

1. **头部和内容被分到了两列。** 参数区本来是一个网格容器，面板插进去的「标题栏」和「分组容器」各自占了一列，所以标题会孤零零停在一侧、参数被挤到另一边，看着像排版坏了。
2. **收起来之后，展开按钮把自己也藏了。** 「展开参数面板」的那个箭头按钮正好就住在标题栏里，旧写法把标题栏一起隐藏了 —— 于是面板进入「收起后再也打不开」的死锁。
3. **面板高度被拉满。** 面板是弹性布局的子元素，默认会被拉伸到和容器一样高，所以哪怕内容隐藏了、占位还是满高，看上去毫无变化。
4. **内容溢出压到画布上。** 面板缺少收缩许可，被内容撑高后，底部的分组标题实际是**被画布盖住的** —— 鼠标点上去命中的是画布，这就是「点不动」的真相。

### 现在的表现

- **折叠与展开一眼能分辨**：创作工坊的「参数设置」从 479px 压成 40px 的一条窄条，白板的面板也不再占满整列
- **折叠后依然能展开**：标题栏保留，箭头按钮可见可点，不会再出现「收了就打不开」
- **收起面板画布真的变宽**：白板画布实测从 750px 增到 878px
- **所有元素都点得到**：每个分组标题都实测过命中测试，底部被遮挡的分组现在也能滚动到并点开
- **手机上不横向溢出**：390×844 视口下参数区已正确降为单列
- **切换很平滑**：尺寸变化有过渡动画，不会闪跳

### 参数依然一点没变

这次**只动布局，不动参数**：35 个白板控件 + 10 个创作工坊控件的取值范围（min/max/step/value）在折叠、展开、全部展开三种状态下逐一比对，差异为空。

## 🔧 调亮度/对比度后色号不刷新，已修好

- **问题**：在白板页拖动「亮度 / 对比度 / 饱和度」滑块后，画面看起来变了，但**格子和右侧图纸上的色号还是老的**，用量清单也不更新。
- **原因**：以前是靠浏览器画布的滤镜功能来调色，这个功能在部分浏览器（包括手机上的 Safari）上**不生效**，颜色没真的变，色号自然也就不会变。
- **现在**：改成自己逐颗算色彩，**任何浏览器都稳定生效**；并且改用和「上传转图纸」同一套配色算法，白板画的色号和转图导出的完全一致。
- 实测：同一格红色，亮度 +50 → A03、+100 → A49、−50 → A26、−100 → A30；对比度和饱和度同样实时变化。

## ✨ 白板新增一批绘画功能

对齐专业拼豆画板站点（pixel-beads）的常用能力，补齐了下面这些：

- **笔刷大小**：1～5 格可选，画笔、橡皮、矩形都跟着变。
- **矩形、直线工具**：拖动画形状，拖动时有半透明预览再落子。
- **移动工具**：单指/鼠标拖动只平移不落笔，方便放大后挪到想画的位置。
- **对称绘制**：左右、上下、四向三种对称，画一笔自动镜像。
- **撤销 + 重做**：补上了重做按钮，也支持 `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`。
- **旋转 90°**：一键把整幅作品转个方向。
- **图片导入两种用法**：
  - **转色号** —— 图片直接变成拼豆矩阵（按当前板型自动缩放并匹配真实色号）；
  - **临摹底图** —— 图片作为半透明参考层铺在底下，方便照着描，还能调透明度。
- **显示开关**：网格线、坐标标尺、格子里的色号文字，都能单独关掉。
- **色号搜索**：在色板上方输入色号或名称（如 `A07`、`Red`）即可筛选；色板按颜色深浅排序，55 色也好找。
- **换色板会重算色号**：从 Artkal 换成 Perler / 马卡龙等，格子里会立刻换成新色板的真实色号。
