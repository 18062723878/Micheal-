## 🔧 调亮度/对比度后色号不刷新，已修好

- **问题**：在白板页拖动「亮度 / 对比度 / 饱和度」滑块后，画面看起来变了，但**格子和右侧图纸上的色号还是老的**，用量清单也不更新。
- **原因**：以前是靠浏览器画布的滤镜功能来调色，这个功能在部分浏览器（包括手机上的 Safari）上**不生效**，颜色没真的变，色号自然也就不会变。
- **现在**：改成自己逐颗算色彩，**任何浏览器都稳定生效**；并且改用和「上传转图纸」同一套配色算法，白板画的色号和转图导出的完全一致。
- 实测：同一格红色，亮度 +50 → A03、+100 → A49、−50 → A26、−100 → A30；对比度和饱和度同样实时变化。

## ✨ 白板新增一批绘画功能

对齐专业拼豆画板站点（pixel-beads）的常用能力，补齐了下面这些：

- **笔刷大小**：1～5 格可选，画笔、橡皮、矩形都跟着变。
- **矩形、直线工具**：拖动画形状，拖动时有半透明预览再落子。
- **移动工具**：单指/鼠标拖动只平移不落笔，方便放大后挪到想画的位置。
- **对称绘制**：左右、上下、四向三种对称，画一笔自动镜像。
- **撤销 + 重做**：补上了重做按钮，也支持 `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`。
- **旋转 90°**：一键把整幅作品转个方向。
- **图片导入两种用法**：
  - **转色号** —— 图片直接变成拼豆矩阵（按当前板型自动缩放并匹配真实色号）；
  - **临摹底图** —— 图片作为半透明参考层铺在底下，方便照着描，还能调透明度。
- **显示开关**：网格线、坐标标尺、格子里的色号文字，都能单独关掉。
- **色号搜索**：在色板上方输入色号或名称（如 `A07`、`Red`）即可筛选；色板按颜色深浅排序，55 色也好找。
- **换色板会重算色号**：从 Artkal 换成 Perler / 马卡龙等，格子里会立刻换成新色板的真实色号。
